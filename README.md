# ItemLoc

Аддон для WoW Forever: ищет предметы по названию на любом из языков (по умолчанию en, ru, de).
Играете на русском, а название предмета нашли на английском сайте? Вставьте его в окошко и получите
предмет с названиями на всех языках, иконкой и тултипом из игры.

## Возможности

- Окно поиска (`/il`) с полем для вставки названия (Ctrl+V)
- **Строгий** и **нестрогий** режимы поиска
- Поиск не зависит от регистра, в том числе для кириллицы и европейских букв (Ä, Ö, É, Ñ)
- Для каждого результата показываются иконка, название из игры (цвет по качеству), ID, тип, слот,
  уровень предмета и названия на всех языках из базы
- Тултип предмета при наведении, Shift+клик вставляет ссылку в чат
- Постраничный просмотр результатов (кнопки, колесо мыши)
- Уведомление, если клиент игры обновился, а база названий собрана для другой сборки

## Установка

1. Скачайте репозиторий (**Code → Download ZIP** или `git clone`).
2. Папка с файлом `ItemLoc.toc` должна называться ровно **`ItemLoc`** и лежать в `Interface\AddOns`
   вашей установки WoW Forever. Если вы скачали ZIP, переименуйте `ItemLoc-main` в `ItemLoc`,
   иначе игра не загрузит аддон.
3. Сгенерируйте файл с данными (см. ниже). Без него аддон запустится, но искать будет нечего.
4. Если игра пишет, что аддон устарел, впишите свой номер в строку `## Interface` в `ItemLoc.toc`.
   Узнать его можно в игре: `/dump (select(4, GetBuildInfo()))`.
5. В игре введите `/reload`.

## Генерация данных

Названия предметов берутся из таблицы `ItemSparse` через [wago.tools](https://wago.tools):

1. **Клиент Forever**: главный источник.
2. **Клиент Classic Era**: запасной. Часть предметов в таблицах Forever отсутствует (Blizzard присылает
   их игре с сервера), поэтому названия таких предметов добираются из Classic Era.

Как запустить:

1. Установите [Python 3](https://www.python.org/downloads/) (при установке отметьте **Add Python to PATH**).
2. Откройте `tools/build_data.py` и при необходимости измените:
   - `FOREVER_BUILDS`: номера сборок Forever, пробуются по очереди (актуальные: https://wago.tools/builds,
     продукт `wow_classic_beta`, версии вида `1.60.1.xxxxx`);
   - `LOCALES`: языки. Например, `"fr": "frFR"` добавляет французский.
3. В папке аддона выполните `python tools/build_data.py`.
4. Скрипт создаст файл `LocalizationData.lua` рядом с `ItemLoc.toc`. В игре выполните `/reload`.

Файл `LocalizationData.lua` в репозиторий не попадает (он в `.gitignore`): он большой и меняется с каждой сборкой.

## Использование

| Команда | Что делает |
|---|---|
| `/il` | открыть или закрыть окно |
| `/il громовая ярость` | открыть окно и сразу выполнить поиск |
| `/il info` | показать сборку клиента, номер Interface и сборку, для которой собрана база |

В окне: **Enter** или кнопка «Найти» запускает поиск, кнопка «Режим» переключает строгий и нестрогий поиск
(выбор запоминается), **«<» и «>»** или колесо мыши листают страницы, Shift+клик по кнопке переходит
в начало или в конец списка, Esc закрывает окно.

### Режимы поиска

- **Строгий**: название на любом из языков должно совпасть с запросом полностью.
  `hearthstone` найдёт Hearthstone, но не Hearthstone Charm.
- **Нестрогий**: подходит часть названия или все слова запроса в любом порядке. Лучшие совпадения идут
  первыми: точное, затем начинающееся с запроса, затем содержащее его, затем содержащее все слова.
  Запрос `ветра искателя` найдёт «Громовая Ярость, благословенный клинок Искателя Ветра».

## Обновление после выхода патча

Аддон сам сообщит в чате при входе в игру, если сборка клиента изменилась, а база собрана для другой.
Что делать:

1. **Игра пишет, что аддон устарел**: поменяйте номер `## Interface` в `ItemLoc.toc` (см. «Установка», п. 4).
2. **Появились новые предметы или названия** (например, после крупного патча): добавьте новую сборку
   Forever в **начало** списка `FOREVER_BUILDS`, запустите `python tools/build_data.py` и сделайте `/reload`.
   Если новой сборки ещё нет на wago.tools, скрипт возьмёт следующую из списка.
3. **Красная ошибка Lua**: включите показ ошибок командой `/console scriptErrors 1` и создайте Issue
   с текстом ошибки.

Характеристики в тултипе после патча обновлять не нужно: тултип рисует сама игра.

## Ограничения

- Названия на других языках есть только для предметов, которые присутствуют в таблицах wago.tools
  (Forever или Classic Era). Совсем новые предметы Forever, которых там нет, не найдутся.
- Для предметов, которые клиент ещё не видел, данные из игры подгружаются с задержкой, а Forever скрывает
  часть данных, пока предмет не найден в игре. В таких случаях тултип может быть пустым, но названия
  из базы остаются.
- Файл данных занимает несколько мегабайт, клиент при входе загружается на секунду-две дольше.
