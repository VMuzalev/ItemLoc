# ItemLoc

Аддон для WoW Forever: ищет предметы по названию на любом из языков (en, ru, de по умолчанию).
Играете на русском, а название предмета нашли на английском сайте? Вставьте его в окошко и получите
название на всех языках.

## Возможности
- Окно поиска (команда `/il`), поле для вставки названия по Ctrl+V
- **Строгий** режим: название должно полностью совпасть (на любом языке)
- **Нестрогий** режим: часть названия или слова в любом порядке, лучшие совпадения сверху
- Не зависит от регистра, в том числе для кириллицы и немецких умлаутов
- При наведении на результат показывается тултип предмета

## Установка
1. Скопируйте папку `ItemLoc` в `Interface\AddOns` вашей установки WoW Forever.
2. Сгенерируйте файл с данными (см. ниже) или скачайте готовый архив из раздела Releases, если он там есть.
3. Если ваш клиент требует другой номер `## Interface` в `ItemLoc.toc`, впишите свой:
   в игре `/dump (select(4, GetBuildInfo()))`.

## Генерация данных
Названия предметов берутся из таблицы `ItemSparse` клиента Forever через [wago.tools](https://wago.tools).

1. Установите Python 3.
2. При необходимости измените в `tools/build_data.py` номер сборки `BUILD` (актуальные: https://wago.tools/builds, продукт `wow_classic_beta`) и список языков `LOCALES`.
3. Запустите: `python tools/build_data.py`
4. Скрипт создаст `ItemLoc/LocalizationData.lua`. После обновления данных в игре выполните `/reload`.

## Использование
| Команда | Что делает |
|---|---|
| `/il` | открыть или закрыть окно |
| `/il громовая ярость` | открыть окно и сразу найти |

Кнопка «Режим» переключает строгий и нестрогий поиск. Выбор запоминается.
